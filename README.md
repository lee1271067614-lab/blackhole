# 卡冈图雅 · Gargantua

超真实、可交互的黑洞 —— 实时 WebGL 逐像素光线追踪的史瓦西黑洞。

## 在线直接看

打开仓库主页的 Pages 地址即可，无需安装：

**https://lee1271067614-lab.github.io/blackhole/**

- 电脑上自动进入桌面版（全画质）
- 手机上自动进入触屏版（竖屏铺满、按钮操作）

## 交互

- 拖动 = 带阻尼的轨道旋转
- 滚轮 / 双指捏合 = 缩放
- 点击 / 点按 = 引力脉冲
- 空格 = 暂停；R = 反转盘向；+/− = 曝光（只改亮度不改颜色）

## 物理要点

- 逐像素反向积分零测地线，黑洞阴影、光子环、引力透镜顶像/底像均由积分自然产生。
- 吸积盘是有厚度的体积等离子；观测温度 `T_obs = g · T_emit`（g = 多普勒 × 引力红移）驱动普朗克黑体连续谱 —— 迎向观察者一侧蓝白、背离一侧暗红，颜色完全由物理决定，没有任何人工配色。
- 史瓦西（不旋转）近似；温度幂、beaming 幂、盘厚为工程/观感标定，非严格辐射转移。
